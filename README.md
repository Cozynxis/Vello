# Vello

A modern social platform inspired by the interaction patterns of X and Instagram, with its own dark visual identity.

## Current foundation
- React + Vite
- Responsive desktop/tablet/mobile layout
- Home feed with For You UI
- Composer and local post creation
- Likes, reposts, bookmarks
- Replies modal
- Explore/search
- Notifications
- Messages UI
- Profile with custom badges
- Settings and dark appearance toggle
- Local persistence through localStorage

## Run locally

```bash
npm install
npm run dev
```

The current release is a frontend foundation. Authentication, database APIs, media storage, realtime chat and production moderation should be connected before public launch.
